BITTU DIGITAL CELEBRATION — GITHUB PAGES
==========================================

Static HTML/CSS/JavaScript website. No backend, Node.js, database, or Netlify required.

FILES
-----
index.html
style.css
script.js
.nojekyll
favicon.svg

The music is generated by JavaScript, so no song file is required.

FLOW
----
1. Surprise envelope
2. Happy Independence Day, Bittu
3. Happy Birthday, Bittu
4. Confetti + celebration melody
5. Watch Again

GITHUB PAGES DEPLOYMENT
-----------------------
1. Create a PUBLIC GitHub repository, e.g. bittu-digital-celebration.
2. Do not create README/.gitignore/license if you plan to upload these files as-is.
3. Open the repository and choose Add file -> Upload files.
4. Upload the CONTENTS of this folder:
   index.html
   style.css
   script.js
   .nojekyll
   favicon.svg
5. Commit the files to the main branch.
6. Open Settings -> Pages.
7. Under Build and deployment, choose Source: Deploy from a branch.
8. Branch: main
9. Folder: / (root)
10. Click Save.
11. Wait for GitHub Pages to finish publishing.
12. Open the Visit site link.

Expected URL:
https://YOUR-GITHUB-USERNAME.github.io/bittu-digital-celebration/

IMPORTANT
---------
index.html must be in the ROOT of the repository, not inside another folder.
The assets folder must also be in the repository root.

For browser sound, the visitor must first tap/click OPEN SURPRISE. The celebration melody then starts.
